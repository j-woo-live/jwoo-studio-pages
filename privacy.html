jwoo-studio 개인정보처리방침

시행일: 2026년 11월 15일

사용자

jwoo-studio는 유튜브 채널 J-Woo 운영자 본인만 사용하는 개인용 도구입니다. 다른 사람의 계정 연결을 받지 않습니다.

접근하는 정보

운영자가 Google 계정으로 연결하면, 운영자 본인 채널의 영상 목록·통계(YouTube Analytics)·댓글을 읽고, 운영자가 직접 실행할 때 영상 업로드와 제목·설명·자막 수정을 합니다.

저장과 전송

  • 받은 정보는 운영자의 컴퓨터 안에서만 쓰며, 외부 서버로 보내거나 제3자와 공유하지 않습니다.
  • 로그인 유지용 토큰은 운영자 컴퓨터의 운영체제 보안 저장소(키체인)에만 저장합니다.
  • 광고·판매·분석 목적으로 쓰지 않습니다.

연결 해제

도구 안의 "유튜브 연결 끊기" 또는 Google 계정 권한 페이지에서 언제든 접근 권한을 철회할 수 있으며, 철회하면 저장된 토큰을 지웁니다.

jwoo-studio의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

jwoo-studio is used only by the owner of the YouTube channel J-Woo on their own computer. Data from Google APIs (the owner's own channel videos, analytics, comments) is used only locally, is never transmitted to other servers or shared, and tokens are stored only in the OS keychain. Access can be revoked at any time via Google Account permissions. Use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.
